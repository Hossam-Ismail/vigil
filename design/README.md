# Design sources

Exported from the published artifacts so they live with the code.

- `deck/` — Vigil marketing deck (Slides artifact: https://claude.ai/artifact/BXx9FzRVMEK3xdomoRybhY). `project/deck.json` sets the slide order.
- `app/` — Vigil app and marketing-site designs (Design artifact: https://claude.ai/artifact/EkLCCYzerka9cU4d8mfdpE). `project/canvas.json` lays out the artboards.

Images and clips are referenced as `/_blob/<id>` assets stored with each artifact; the originals and the scripts that render them are in `brand/` and `backend/scripts/`.
