How it works

01

Describe it

“Text Maria when Line 1's staging area runs empty, and add a restock task in HubSpot.”

02

It trains a model

A vision model built for that one request, ready in minutes. 

03

It watches and acts

Every frame, all day. A stronger AI double-checks each alert, then Vigil texts, files the ticket or calls your systems.

Self-improving with user feedback

Vigil

02

Under the hood: a large vision-language model reads the request, finds the right spot on the camera and gathers labeled examples; a small model trained only for that request watches every frame; the large model double-checks each alert before anything is sent. The follow-up is part of the request: iMessage, HubSpot, Slack or any system through a webhook. Each answer someone gives (a YES or NO reply, a correction in the app) and each alert the double-check rejects is added to that watch's training set, and it retrains on the spot.
