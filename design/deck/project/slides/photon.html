This is Vigil's entry for Photon's Agents in iMessage challenge: an agent that lives in iMessage, built on Spectrum, Photon's open-source SDK (spectrum-ts with the local iMessage provider, on a Mac signed in to Messages; nothing to install on the phone). It goes both ways. Vigil texts first: when a watch fires and the double-check agrees, the alert arrives with the photo, and now and then it asks whether it was right, so a YES or NO retrains that watch. And you can text Vigil: "Text me when a package is left at the door" builds a new watch (through the same safety rules as the app); "What's happening on the plaza?" sends back a live photo with faces blurred and what it sees; "How many people are on the plaza?" reads the live count; "What are you watching?" lists every watch; "Pause dock" and "Resume dock" control them. Spectrum carries the whole conversation: it streams incoming messages, marks them read, shows typing while Vigil thinks, reacts with a tapback and replies with text and photos in the same thread. Only the owner's number, set in Settings, can talk to Vigil; texts from anyone else get no answer.
